## Implementation Notes

### Motion
- All Framer Motion animations gated behind `useReducedMotion()` hook
- Three.js globe animations pause when `prefers-reduced-motion: reduce`
- 2D fallbacks (SVG donut chart + data table) auto-rendered under reduced-motion

### Keyboard Navigation
- Tab order: Skip link → Nav → Main content → Activity log → Feed → Metric strip
- Globe: keyboard-accessible via fallback 2D view when motion is reduced
- Parallel-You timeline scrubber: left/right arrow keys = month navigation
- Chat panel: Escape closes it, focus returns to FAB button

### ARIA Live Regions
```html
<!-- Streaming agent responses -->
<div aria-live="polite" aria-label="Carbon AI response">
  {streamingContent}
</div>

<!-- Globe CO₂e updates -->
<div aria-live="polite" className="sr-only">
  Your total is now {co2eKg} kg CO₂e
</div>

<!-- Activity feed new items -->
<div aria-live="polite" aria-label="Activity feed">
  {activities}
</div>
```

### Color Contrast
All text meets WCAG 2.2 AA minimum ratios:
- `text-text-primary` (`#E8EDF5`) on `space-black` (`#05080F`): 16.2:1 ✅
- `text-neon-cyan` (`#00F5D4`) on `space-black`: 8.7:1 ✅
- `text-text-secondary` (`#8892A4`) on `space-black`: 5.1:1 ✅
- `text-text-muted` (`#4A5568`) on `space-black`: 3.2:1 ⚠️ (used only for decorative/supplementary text — check in Sprint 2)

### Focus Indicators
```css
:focus-visible {
  outline: 2px solid #00F5D4;
  outline-offset: 2px;
}
```
Applied globally — never `outline: none` without replacement.
